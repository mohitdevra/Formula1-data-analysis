# Formula 1 Data Analysis

An end-to-end Formula 1 data analysis project using SQL, Power BI and Excel.

## Project Overview

This project analyzes Formula 1 racing data to uncover insights about drivers, teams, races and performance over different seasons.

The project is being developed in multiple stages:

- Data exploration and analysis using SQL
- Data visualization and dashboard development using Power BI
- Data analysis and dashboard development using Excel

## Dataset

The dataset contains Formula 1 data including:

- Drivers
- Constructors/Teams
- Races
- Results
- Lap times
- Pit stops
- Qualifying
- Driver standings
- Constructor standings

## Tools & Technologies

- MySQL
- SQL
- Power BI
- Excel
